1. Approaches to AI

Before building intelligent systems, AI needed a working definition of "intelligence" and general strategies for searching through huge spaces of possible solutions.

Key ideas

  • Turing Test: judges intelligence behaviorally — a machine "passes" if a human evaluator can't reliably distinguish its conversation from a human's.
  • Rational agent approach: defines intelligence functionally — an agent is rational if it acts to maximize its expected performance measure, given what it has perceived and knows.
  • State space representation: models a problem as states (configurations), operators (actions moving between states), an initial state, and goal state(s) — search finds a path from start to goal.
  • Heuristic search: uses a heuristic function estimating "distance to goal" to guide search toward promising states first (e.g. A*, best-first search), rather than exploring blindly.
  • Game playing & Min-Max: in adversarial two-player games, Min-Max search assumes the opponent also plays optimally, choosing moves that minimize the opponent's best-case advantage.
  • Alpha-beta cutoff: prunes branches of the Min-Max tree that provably cannot affect the final decision, cutting search time without changing the result.

2. Knowledge Representation

For a system to reason, it first needs a way to represent facts, relationships, and general knowledge about its domain.

Key ideas

  • Logic: propositional/predicate logic represents facts and rules formally, enabling sound deductive inference.
  • Semantic networks: represent knowledge as a graph of concept nodes connected by labeled relationship edges (e.g. is-a, has-a).
  • Frames: structured records representing a stereotyped object/situation, with named "slots" holding attribute values (or even procedures).
  • Rules & scripts: production rules (if-then) encode conditional knowledge; scripts represent expected sequences of events for common, stereotyped situations (e.g. "eating at a restaurant").
  • Conceptual dependency & ontologies: conceptual dependency represents sentence meaning in a language-independent form of primitive actions; ontologies formally define a shared vocabulary of concepts and relationships within a domain.
  • Expert systems: separate a knowledge base (domain facts/rules) from an inference engine (the reasoning mechanism), letting the same engine work across different domains.
  • Handling uncertainty: certainty factors, fuzzy logic, and Bayesian probability let systems reason with incomplete or imprecise knowledge instead of requiring strict true/false facts.

3. Planning

Planning figures out a sequence of actions that will transform the world from its current state into a desired goal state.

Key ideas

  • Components of a planning system: a representation of states, a set of operators/actions (with preconditions and effects), an initial state, and a goal description.
  • Linear vs. non-linear planning: linear planning produces a single, totally ordered sequence of actions; non-linear planning allows sub-plans to interleave, only ordering steps when truly necessary.
  • Goal stack planning: maintains a stack of goals and operators, repeatedly resolving the top goal — pushing new subgoals if its preconditions aren't yet satisfied.
  • Hierarchical planning: plans at a high, abstract level first, then progressively refines each abstract step into more detailed sub-actions.
  • STRIPS: represents each operator with preconditions plus add/delete lists describing exactly how it changes the world state — a foundational formalism for classical planning.
  • Partial-order planning: builds a plan as a partially ordered set of steps, committing to an ordering between two steps only when required to avoid conflicts — more flexible than strictly linear plans.

4. Natural Language Processing

NLP lets machines process human language, working through several levels of analysis to move from raw text to meaning and intent.

Key ideas

  • Grammar & language: a formal grammar defines which sentences are syntactically valid in a language, similar in spirit to programming-language grammars.
  • Parsing techniques: syntactic parsers apply grammar rules to determine a sentence's structure (e.g. its parse tree), analogous to compiler parsing but for natural, often ambiguous language.
  • Semantic analysis: derives the literal meaning of a sentence from its syntactic structure and the meanings of its words.
  • Pragmatics: interprets an utterance's intended meaning using context beyond the literal words — situation, speaker intent, and conversational conventions.

5. Multi Agent Systems

Some problems are best solved by several autonomous agents cooperating (or competing) rather than one centralized program.

Key ideas

  • Agents vs. objects: unlike a passive object that only responds to method calls, an agent autonomously decides its own actions based on its goals and perceptions.
  • Agents and expert systems: an agent can embed expert-system-style reasoning to decide how to act within its environment.
  • Generic structure of a multiagent system: multiple interacting agents, each with its own knowledge/goals, that must coordinate (cooperatively or competitively) to solve a larger task.
  • Semantic Web: extends the Web with machine-readable, ontology-based metadata, letting software agents interpret and act on web content, not just display it.
  • Agent communication: standardized agent communication languages (e.g. KQML, FIPA-ACL) define shared message formats ("performatives") so agents can exchange requests, information, and commitments.
  • Knowledge sharing using ontologies: shared ontologies give agents a common vocabulary so messages are interpreted consistently across different agents/systems.
  • Agent development tools: frameworks/platforms providing infrastructure (messaging, lifecycle management) for building and deploying multiagent systems.

6. Fuzzy Sets

Fuzzy logic extends classical set theory and logic to handle the graded, imprecise categories common in everyday reasoning (e.g. "warm," "tall," "fast").

Key ideas

  • Notion of fuzziness: unlike a classical (crisp) set, a fuzzy set allows partial membership — an element can belong "somewhat" (a degree between 0 and 1), not just fully in or out.
  • Membership functions: define exactly how much (0 to 1) each possible value belongs to a fuzzy set (e.g. how "warm" 25°C is).
  • Fuzzification & defuzzification: fuzzification converts a crisp input into fuzzy membership degrees; defuzzification converts a fuzzy result back into a single crisp output value.
  • Operations on fuzzy sets: fuzzy union, intersection, and complement generalize the classical set operations using membership degrees.
  • Linguistic variables: variables whose values are words/phrases (e.g. "low," "medium," "high") rather than numbers, each represented by a fuzzy set.
  • Fuzzy relations, rules & inference: fuzzy if-then rules relate linguistic input and output variables; fuzzy inference combines active rules to produce a fuzzy conclusion.
  • Fuzzy control systems: apply fuzzy rule-based reasoning to compute control outputs directly from imprecise, continuous sensor inputs (e.g. in washing machines, climate control).

7. Genetic Algorithms (GA)

Genetic algorithms search for good solutions by mimicking natural selection — evolving a population of candidate solutions over many generations.

Key ideas

  • Encoding strategies: candidate solutions ("chromosomes") are encoded as bit strings, real-valued vectors, or other representations suited to the problem.
  • Genetic operators: selection favors fitter individuals to reproduce; crossover combines parts of two parent chromosomes to form offspring; mutation makes small random changes, maintaining diversity and helping avoid premature convergence.
  • Fitness function: scores how good a candidate solution is at solving the problem — the driving force behind selection.
  • GA cycle: initialize a population → evaluate fitness → select parents → apply crossover/mutation to produce the next generation → repeat until a stopping criterion (e.g. good-enough fitness) is met.
  • Problem solving using GA: well suited to large, complex search spaces where gradient information isn't available (e.g. optimization, scheduling, design search).

8. Artificial Neural Networks (ANN)

ANNs loosely model biological neurons — networks of simple, connected units that learn patterns from data rather than being explicitly programmed.

Key ideas

  • Supervised learning: trains on labeled input-output pairs, adjusting weights (e.g. via backpropagation) to reduce prediction error.
  • Unsupervised learning: finds structure/clusters in unlabeled data — e.g. Self-Organizing Maps (SOMs) project data onto a lower-dimensional grid while preserving similarity relationships.
  • Reinforcement learning: an agent learns by trial and error, adjusting behavior based on reward/penalty feedback from its environment rather than labeled examples.
  • Single perceptron: the simplest neural unit; it can only correctly separate linearly separable patterns (famously, it cannot learn XOR).
  • Multi-Layer Perceptron (MLP): adding hidden layers (with non-linear activation functions) lets a network approximate non-linear, more complex functions that a single perceptron cannot.
  • Self-Organizing Maps: unsupervised networks that learn a topological, low-dimensional representation of high-dimensional input data.
  • Hopfield Network: a recurrent, fully connected network that acts as associative (content-addressable) memory, able to recall a complete stored pattern from a partial or noisy version of it.
