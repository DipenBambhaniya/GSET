1. Mathematical Logic

Mathematical logic gives the formal language used to state and prove everything else in discrete mathematics. Propositional logic works with statements (propositions) that are either true or false, combined using connectives (¬, ∧, ∨, →, ↔). Predicate logic extends this with predicates like P(x) and quantifiers ∀ (for all) and ∃ (there exists), so statements can talk about objects in a domain rather than fixed facts.

Key ideas

  • Propositional equivalences: two propositions are logically equivalent if they have identical truth tables (e.g. De Morgan's laws, distributive laws).
  • Normal forms: every propositional formula can be written in Conjunctive Normal Form (AND of ORs) or Disjunctive Normal Form (OR of ANDs).
  • Quantifiers & nested quantifiers: order matters — ∀x∃y P(x,y) is generally not the same as ∃y∀x P(x,y).
  • Negating quantifiers: ¬∀x P(x) ≡ ∃x ¬P(x), and ¬∃x P(x) ≡ ∀x ¬P(x).
  • Rules of inference: Modus Ponens (p, p→q ⊢ q), Modus Tollens (¬q, p→q ⊢ ¬p), Hypothetical Syllogism, Resolution — the building blocks of formal proofs.

2. Sets and Relations

A set is an unordered collection of distinct elements. Relations describe how elements of one (or the same) set relate to each other, and are the formal basis for functions, orderings, and equivalence classes.

Key ideas

  • Set operations: union (∪), intersection (∩), difference (−), complement, Cartesian product (A × B).
  • Representation: roster form, set-builder form, Venn diagrams; properties include commutativity, associativity, De Morgan's laws for sets.
  • Relation: a subset of A × B. Properties on a set A: reflexive (a R a), symmetric (a R b ⇒ b R a), antisymmetric, transitive (a R b ∧ b R c ⇒ a R c).
  • Equivalence relation = reflexive + symmetric + transitive → partitions the set into disjoint equivalence classes.
  • Partial order = reflexive + antisymmetric + transitive → represented visually with a Hasse diagram.

3. Counting, Mathematical Induction and Discrete Probability

Counting techniques answer "how many?" without listing every possibility, induction proves statements for all natural numbers, and discrete probability quantifies uncertainty over finite/countable outcomes.

Key ideas

  • Basics of counting: Sum rule (either/or → add), Product rule (and-then → multiply).
  • Pigeonhole principle: if n+1 items go into n boxes, some box holds ≥2 items.
  • Permutations (order matters): P(n,r) = n! / (n−r)!. Combinations (order doesn't matter): C(n,r) = n! / (r!(n−r)!).
  • Inclusion–Exclusion: |A ∪ B| = |A| + |B| − |A ∩ B| (extends to more sets by alternating +/−).
  • Mathematical induction: prove P(1) (base case), then assume P(k) (inductive hypothesis) and prove P(k+1) (inductive step).
  • Probability & Bayes' theorem: P(A|B) = P(B|A)·P(A) / P(B) — used to update beliefs given new evidence.

4. Group Theory

Group theory studies algebraic structures built from a set with one or more operations, capturing the idea of "symmetry" formally.

Key ideas

  • Semigroup: a set with an associative binary operation.
  • Group (G, *): closure, associativity, identity element, and every element has an inverse.
  • Abelian group: a group that is also commutative.
  • Subgroup: a subset of a group that is itself a group under the same operation.
  • Homomorphism preserves structure (f(a*b) = f(a)*f(b)); an isomorphism is a bijective homomorphism; an automorphism is an isomorphism from a group to itself.
  • Rings, Integral Domains, Fields: a ring has two operations (+, ×) with + forming an abelian group and × distributing over +; an integral domain is a commutative ring with no zero divisors; a field additionally has multiplicative inverses for all nonzero elements.
  • Applications: cryptography (RSA, elliptic curves), coding theory, symmetry analysis in chemistry/physics.

5. Graph Theory

A graph models pairwise relationships between objects: vertices (nodes) connected by edges. Graphs underpin networks, scheduling, routing, and data structures.

Key ideas

  • Types: simple graph (no loops/multi-edges), multigraph (repeated edges allowed), weighted graph (edges carry costs).
  • Paths & circuits: a path repeats no vertices; a circuit returns to its start. Dijkstra's algorithm finds shortest paths in weighted graphs.
  • Eulerian circuit: exists iff every vertex has even degree (connected graph). Hamiltonian circuit: visits every vertex exactly once — no simple general test exists.
  • Planar graphs: can be drawn without edge crossings; satisfy Euler's formula V − E + F = 2.
  • Graph coloring: chromatic number = minimum colors so adjacent vertices differ; bipartite graphs are exactly the 2-colorable graphs (no odd cycles).
  • Trees: connected, acyclic graphs with n vertices and n−1 edges; rooted trees have a designated root; prefix codes (e.g. Huffman coding) are represented as binary trees; traversals include pre-order, in-order, post-order.
  • Spanning trees & cut-sets: a spanning tree connects all vertices with the fewest edges (n−1); Kruskal's/Prim's algorithms build a minimum spanning tree; a cut-set is a minimal set of edges whose removal disconnects the graph.

6. Boolean Algebra

Boolean algebra formalizes logic with two values (0/1, false/true) and the operations AND (·), OR (+), NOT (′) — the mathematical basis of digital circuit design.

Key ideas

  • Boolean functions: expressed as truth tables, Sum-of-Products (SOP) or Product-of-Sums (POS) expressions.
  • Basic identities: Identity, Null, Idempotent, Complement, and De Morgan's laws: (A·B)′ = A′+B′ and (A+B)′ = A′·B′.
  • Simplification: algebraic manipulation or Karnaugh maps (K-maps) group adjacent 1s (in powers of 2) to minimize the number of literals/terms — fewer gates in the resulting circuit.
  • Absorption law: A + A·B = A, and A + A′·B = A + B.

7. Optimization

Optimization finds the best (maximum or minimum) value of an objective subject to constraints — central to operations research and resource planning.

Key ideas

  • Linear Programming (LP): maximize/minimize a linear objective subject to linear constraints. Graphical solution works for 2 variables; the optimum lies at a vertex of the feasible region.
  • Simplex method: an algebraic, iterative method that moves between feasible vertices to reach the optimum for any number of variables. The Dual Simplex method handles problems that start dual-feasible but primal-infeasible.
  • Sensitivity analysis: studies how the optimal solution changes as objective coefficients or constraint limits (RHS) vary.
  • Integer Programming: like LP, but some/all variables must be integers — solved via branch-and-bound or cutting planes.
  • Transportation & Assignment models: special LP structures for shipping goods from sources to destinations (transportation) or assigning tasks to agents one-to-one (assignment, solved via the Hungarian method) at minimum cost.
  • PERT–CPM: network diagrams represent project activities; the critical path is the longest path through the network and determines the minimum project duration; resource levelling smooths resource usage over time; cost trade-offs (crashing) balance time vs. cost.
